## 12. Бонусы

| Требование | Статус | Где |
|---|---|---|
| Правило 1: сдача в пункт, бонусы за кг по виду, личный QR | ✅ (этап 1) | `drop_off_create`, `my_personal_qr` (код меняется каждые 5 мин) |
| Правило 2: недельный пул дома = кг вторсырья площадки × ставка × коэффициент чистоты, поровну активным жителям | ✅ | `site_pool_payout`; повторный запуск за ту же неделю ничего не начисляет |
| Баланс = сумма транзакций | ✅ | триггер `bonus_balance` + проверка `bonus_balance_check` в админке |
| История с причиной | ✅ | `/bonuses/`: тип, формула начисления, дата |
| Защита: лимит в день, уведомления админа о необычных сдачах | ✅ | лимит — в `drop_off_create`; список — `bonus_alerts` в админке |

## 13. Маркетплейсы

| Требование | Статус | Где |
|---|---|---|
| Магазин: наши продукты и скидки партнёров, оплата бонусами полностью или частично, промокод | ✅ | `shop_redeem` (повтор по `client_id` не списывает второй раз), `my_orders` |
| B2B: объявление с видом, объёмом, чистотой, ценой за т, происхождением (партии → площадки, даты) | ✅ | `market_create_listing` проверяет объём в партиях оператора; `market_listings` |
| Заявка покупателя и статусы сделки new → accepted → done / cancelled | ✅ | `market_request`, `market_set_status`, `market_my_deals`; объявление «в резерве» / «продано» |
| Справочник «во что перерабатывается» и где принимают | ✅ | `/recycling/`: `waste_rules_list` + пункты приёма и переработчики |
| Кабинет партнёра, маркетплейс вещей (P2) | ➖ | не сделано |
